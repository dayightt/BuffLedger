# Probe findings — 2026-09-18, build 1.60.1.69893 (Interface 16001)

Recorded from a throwaway probe addon on a level-low Hunter, solo, open world, out of combat; plus the client's own `Blizzard_BuffFrame` / `AuraUtil` source for the same build.

## Aura data

`C_UnitAuras.GetAuraDataByIndex("player", i, "HELPFUL"|"HARMFUL")` returns a plain table with every field plain out of combat:

```
auraInstanceID, name, icon (fileID), spellId, duration, expirationTime, applications (0 when unstacked),
sourceUnit ("player" for self-casts), dispelName ("Magic" even on some helpful buffs, e.g. Spirit),
isHelpful, isHarmful, isRaid, isStealable, isBossAura, canApplyAura, canActivePlayerDispel,
isFromPlayerOrPlayerPet, nameplateShowAll/Personal, isNameplateOnly, hideOnPartyFrames,
isTankRoleAura, isHealerRoleAura, isDPSRoleAura, timeMod, points
```

Permanent auras: `duration == 0` and `expirationTime == 0`. The client's own buff frame computes `expirationTime - GetTime()` in plain Lua for player auras, so player aura data is not expected to be secret; every read is still guarded. In-combat and instanced dumps were not captured (low level) — re-check when possible.

Also present: `C_UnitAuras.GetAuraDataByAuraInstanceID`, `GetAuraDuration`, `DoesAuraHaveExpirationTime`, `GetAuraDispelTypeColor`, `CancelAuraByInstanceID` (protected — not used), `GetUnitAuras`, `GetAuraSlots`/`GetAuraDataBySlot`.

## UNIT_AURA payload

`updateInfo` is a plain table: `isFullUpdate` plus any of `addedAuras` (full aura tables), `updatedAuraInstanceIDs`, `removedAuraInstanceIDs`. Eating food produced `addedAuras` with one entry; cancelling produced `removedAuraInstanceIDs`.

## Frames

- `BuffFrame` and `DebuffFrame` are not protected; `Hide()` works out of combat with no forbidden-action dialog. (Reparenting was not exercised; hiding plus an `OnShow` re-hide is sufficient.)
- `AuraButtonTemplate` is instantiable by addons. Its art (`AuraButtonArtTemplate`, 30×40):
  - `Icon` texture 30×30 at TOP, BACKGROUND layer.
  - `Duration` FontString `GameFontNormalSmall` (FRIZQT 10, gold `NORMAL_FONT_COLOR`; turns `HIGHLIGHT_FONT_COLOR` under `BUFF_DURATION_WARNING_TIME`), anchored TOP → Icon BOTTOM.
  - `Count` FontString `NumberFontNormal` (ARIALN 14 OUTLINE), BOTTOMRIGHT → Icon BOTTOMRIGHT (-2, 2), shown when `applications > 1`.
  - `DebuffBorder` texture 40×40 OVERLAY centred on Icon; atlas from `DEBUFF_DISPLAY_INFO[dispelType]`: `ui-debuff-border-<magic|curse|disease|poison|bleed>-icon` (border **with the circular corner dispel icon**) or `-noicon`; `ui-debuff-border-default-noicon` for none. Which one is chosen by the Edit Mode "Show Dispel Type" setting (`AuraContainer.showDispelType`). Standalone dispel icons: `RaidFrame-Icon-Debuff<Magic|Curse|Disease|Poison|Bleed>`.
  - `TempEnchantBorder` texture 32×32 `Interface\Buttons\UI-TempEnchant-Border` centred on Icon, shown for weapon enchants.
  - `Symbol` FontString `TextStatusBarText` TOPLEFT (2,-2) — colourblind-mode dispel letter.
- `BUFF_WARNING_TIME = 31` (icon alpha pulses below it), `BUFF_DURATION_WARNING_TIME` (duration text turns white), `BUFF_MAX_DISPLAY = 32`, `DEBUFF_MAX_DISPLAY = 16`.
- Duration text uses `SecondsToTimeAbbrev` wrapped in `securecall` because of taint — the addon formats its own text instead.

## Cancelling

A `SecureActionButtonTemplate` button with `type="cancelaura"`, `unit="player"`, `index=1` cancels the aura on click (registered `AnyDown, AnyUp` fires twice; register one). Attributes cannot change during combat, so a button whose aura changed mid-combat carries a stale attribute. Mitigation: stable aura→button assignment and `spell=<name>` instead of `index` (a stale name that no longer exists is a no-op).

Weapon enchants: `C_Item.GetWeaponEnchantInfo(slotID)` for `slotID` in `Enum.WeaponSlot` (0 main hand → inventory 16, 1 off hand → 17, 2 ranged → 18) returns a list of `{ hasEnchant, timeLeft (ms), charges, enchantType, enchantIconID }`. Cancel via `C_Spell.CancelItemTempEnchantment(slotID, enchantType)`. Tooltip via `GameTooltip:SetInventoryItem("player", 16|17|18)`. The legacy `GetWeaponEnchantInfo()` global still exists.
